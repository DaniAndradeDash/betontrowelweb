# Prompt para Gemini: Generador de Documento de Feedback Profesional

Copia y pega el siguiente prompt en la plataforma de Gemini para generar una plantilla profesional de seguimiento de cambios para el sitio web de Beton Trowel México.

---

## PROMPT A COPIAR:

"Actúa como un experto en Gestión de Proyectos Web y Diseño UX. Necesito que generes una plantilla profesional para un **'Documento de Registro de Observaciones y Cambios'** para un cliente de un sitio web corporativo (arquitectura estática con Next.js).

El documento debe ser estructurado, fácil de leer y visualmente limpio (estilo corporativo moderno). Debe incluir las siguientes secciones obligatorias:

1.  **Portada:** Nombre del proyecto, Fecha de entrega, Versión del documento, Responsable.
2.  **Instrucciones de llenado:** Breve guía para el cliente sobre cómo reportar un cambio (importancia de ser específico y adjuntar capturas de pantalla).
3.  **Tabla de Seguimiento de Cambios (Estructura de columnas):**
    *   ID (Autoincremental)
    *   Sección/Página (Ej: Home, Productos, Contacto)
    *   Ubicación específica (Elemento exacto, ej: Header, Banner, Footer)
    *   Tipo de cambio (Corrección, Mejora, Nuevo Contenido, Imagen/UI)
    *   Prioridad (Alta, Media, Baja)
    *   Descripción detallada de la observación (Qué debe cambiarse y por qué)
    *   Evidencia (Espacio reservado para [Insertar Captura de Pantalla/Link a video])
    *   Estado (Pendiente, En Proceso, Completado)
4.  **Notas adicionales:** Espacio para consideraciones de marca dual (Beton Trowel / Equipos y Superficies de México).

Por favor, diseña la plantilla para que sea legible tanto en un formato de procesador de texto (como Google Docs o Word) como exportable a PDF. Usa un tono profesional, claro y orientado a la eficiencia."
