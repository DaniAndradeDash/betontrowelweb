# SEO_GUIDE.md

# Objetivo

Este documento define la estrategia SEO del proyecto para garantizar un posicionamiento sólido, una excelente indexación y una estructura optimizada para buscadores sin comprometer la experiencia del usuario.

El SEO deberá implementarse desde la arquitectura del proyecto y no añadirse al final del desarrollo.

---

# Objetivos SEO

El sitio deberá:

- Posicionar la marca Beton Trowel en México.
- Posicionar Equipos y Superficies de México como distribuidor oficial.
- Generar tráfico orgánico de calidad.
- Captar clientes potenciales.
- Mejorar la autoridad del dominio.
- Facilitar la indexación de todas las páginas.

---

# Estrategia

El contenido deberá responder a la intención de búsqueda del usuario.

Se priorizarán búsquedas relacionadas con:

- maquinaria ligera
- acabado de concreto
- allanadoras
- reglas vibratorias
- vibradores de concreto
- cortadoras de piso
- equipos para construcción
- maquinaria para concreto
- distribuidores Beton Trowel
- Beton Trowel México
- Equipos y Superficies de México

No se deberá escribir únicamente para Google.

El contenido debe resolver dudas reales del usuario.

---

# Arquitectura SEO

Cada página deberá contar con:

- URL limpia
- Metadata única
- H1 único
- Jerarquía correcta de encabezados
- Open Graph
- Twitter Cards
- JSON-LD
- Canonical
- Sitemap
- Robots.txt

---

# Metadata

Cada página deberá definir:

- title
- description
- keywords (si aplica)
- openGraph
- twitter
- robots
- alternates
- canonical

Nunca reutilizar el mismo título entre páginas.

Las descripciones deberán ser únicas.

---

# Titles

Buenas prácticas:

- Máximo 60 caracteres.
- Incluir palabra clave principal.
- Incluir la marca cuando aporte valor.
- Ser naturales.
- No utilizar relleno de palabras clave.

Ejemplo:

Beton Trowel México | Equipos para Acabado de Concreto

---

# Meta Description

Debe:

- Tener entre 140 y 160 caracteres.
- Explicar claramente el contenido.
- Incluir palabras clave de forma natural.
- Invitar al clic.

Evitar descripciones duplicadas.

---

# Headings

La jerarquía deberá mantenerse siempre.

Una sola etiqueta H1 por página.

Después:

- H2
- H3
- H4

Nunca utilizar encabezados únicamente por tamaño visual.

---

# URLs

Las URLs deberán ser:

- Cortas.
- Descriptivas.
- Sin caracteres especiales.
- En minúsculas.
- Separadas por guiones.

Ejemplos:

/productos

/maquinaria-ligera

/allanadoras

No utilizar parámetros innecesarios.

---

# Contenido

Todo el contenido deberá ser:

- Original.
- Claro.
- Útil.
- Bien estructurado.
- Fácil de leer.

Evitar:

- Keyword stuffing.
- Texto generado sin sentido.
- Contenido repetido.

---

# Imágenes

Todas las imágenes deberán:

- Estar optimizadas.
- Tener atributo alt descriptivo.
- Mantener nombres de archivo descriptivos.
- Utilizar next/image.

Ejemplo:

beton-trowel-allanadora-36.webp

No utilizar:

IMG_3848.jpg

---

# Open Graph

Cada página deberá incluir:

- title
- description
- image
- type
- locale
- url

La imagen deberá representar correctamente el contenido.

---

# Twitter Cards

Implementar:

- summary_large_image

Incluyendo:

- title
- description
- image

---

# Datos estructurados

Implementar JSON-LD cuando corresponda.

Priorizar:

- Organization
- LocalBusiness
- Product
- BreadcrumbList
- WebSite
- WebPage
- FAQPage (cuando exista)

Nunca generar datos estructurados falsos.

---

# Organización

Toda la información de la empresa deberá mantenerse consistente.

Ejemplo:

Nombre

Equipos y Superficies de México

Distribuidor

Beton Trowel México

Logo

Dirección

Teléfono

Correo

Sitio web

Redes sociales

Toda esta información deberá mantenerse sincronizada.

---

# Enlaces internos

Todas las páginas deberán estar conectadas.

Evitar páginas huérfanas.

Utilizar textos descriptivos.

No abusar de enlaces repetidos.

---

# Enlaces externos

Solo enlazar sitios de confianza.

Preferir:

- Fabricante
- Redes oficiales
- Certificaciones

Los enlaces externos deberán abrir en nueva pestaña cuando corresponda.

---

# Rendimiento SEO

El SEO también depende del rendimiento.

Objetivos:

- LCP bajo.
- CLS mínimo.
- INP óptimo.
- Lighthouse SEO superior a 95.

Toda optimización deberá considerar Core Web Vitals.

---

# Accesibilidad

Una buena accesibilidad mejora el SEO.

Siempre incluir:

- Alt.
- Labels.
- Contraste adecuado.
- Navegación por teclado.
- HTML semántico.

---

# Indexación

Mantener:

- robots.txt actualizado.
- sitemap.xml actualizado.
- URLs canónicas.
- Sin contenido duplicado.

---

# Contenido futuro

Si en el futuro se agregan nuevas páginas deberán mantener:

- Metadata única.
- Títulos únicos.
- Descripciones únicas.
- URLs limpias.
- Encabezados correctos.
- Contenido original.

---

# Filosofía SEO

El objetivo no es únicamente aparecer en Google.

El objetivo es convertirse en la referencia digital para quienes buscan maquinaria ligera, equipos para acabado de concreto y soluciones profesionales relacionadas con Beton Trowel en México.

Cada página debe aportar valor real al usuario antes que intentar posicionar una palabra clave.

---

# Regla principal

Toda decisión de desarrollo deberá responder esta pregunta:

> ¿Este cambio mejora la visibilidad del sitio sin afectar la experiencia del usuario?

Si la respuesta es no, deberá replantearse.
