# Principios visuales

Todo el sitio debe mantener:

- Excelente uso del espacio.
- Jerarquía clara.
- Tipografía consistente.
- Diseño limpio.
- Aire visual.
- Contenido fácil de escanear.
- Excelente contraste.

---

# Diseño moderno

Cuando propongas mejoras deberás inspirarte en sitios corporativos modernos.

Priorizar:

- Grandes espacios.
- Layout limpio.
- Imágenes protagonistas.
- Tipografía elegante.
- Cards bien organizadas.
- Componentes minimalistas.
- Excelente legibilidad.

Evitar diseños antiguos o sobrecargados.

---

# Tipografía

La tipografía es uno de los pilares del proyecto.

Siempre revisar:

- Tamaños.
- Pesos.
- Espaciado.
- Altura de línea.
- Longitud de párrafos.

Nunca utilizar demasiados tamaños distintos.

La jerarquía debe sentirse natural.

---

# Paleta de colores

No modificar la identidad cromática existente.

Las mejoras deberán realizarse utilizando la paleta oficial.

Evitar:

- Nuevos colores sin justificación.
- Gradientes innecesarios.
- Exceso de colores secundarios.

---

# Layout

Las páginas deberán tener un ritmo visual uniforme.

Cada sección debe tener:

- Introducción.
- Desarrollo.
- Cierre.

Evitar bloques enormes de información.

Dividir el contenido inteligentemente.

---

# Espaciado

Siempre priorizar:

- Márgenes amplios.
- Padding consistente.
- Separación clara entre bloques.

El espacio en blanco también comunica calidad.

---

# Componentes

Todos los componentes deberán sentirse parte del mismo sistema.

Revisar constantemente:

- Botones.
- Cards.
- Formularios.
- Badges.
- Etiquetas.
- Iconografía.
- Secciones.

Nunca permitir componentes aislados visualmente.

---

# Imágenes

Las imágenes deben:

- Comunicar calidad.
- Mostrar maquinaria real.
- Mantener excelente resolución.
- Estar correctamente recortadas.
- Tener buena composición.

Evitar imágenes genéricas cuando existan fotografías reales.

---

# Responsive Design

Todo diseño deberá adaptarse perfectamente a:

- Mobile
- Tablet
- Laptop
- Desktop

No diseñar únicamente para escritorio.

---

# Conversión

Cada página debe guiar naturalmente al usuario hacia el contacto.

Los llamados a la acción deben sentirse naturales.

Nunca utilizar estrategias agresivas.

---

# Formularios

Visualmente deberán transmitir:

- Simplicidad.
- Confianza.
- Profesionalismo.

La experiencia debe ser rápida y clara.

---

# Accesibilidad visual

Siempre verificar:

- Contraste.
- Tamaños mínimos.
- Estados de foco.
- Legibilidad.
- Espaciados.

Un buen diseño también debe ser accesible.

---

# Animaciones

Las animaciones no son protagonistas.

Únicamente utilizar:

- Hover.
- Focus.
- Transiciones suaves.
- Microinteracciones.

Nunca utilizar animaciones que distraigan del contenido.

---

# Evaluación de una interfaz

Antes de aprobar cualquier diseño pregúntate:

- ¿La información se entiende rápidamente?
- ¿Existe una jerarquía clara?
- ¿El usuario sabe qué hacer?
- ¿La marca transmite confianza?
- ¿Se mantiene la identidad visual?
- ¿Todo parece pertenecer al mismo sistema?
- ¿Hay elementos innecesarios?

Si alguna respuesta es negativa, replantea la solución.

---

# Forma de responder

Cuando analices una interfaz deberás:

1. Detectar problemas visuales.
2. Explicar por qué afectan la experiencia.
3. Proponer mejoras concretas.
4. Mantener la identidad del proyecto.
5. Justificar cada decisión desde UX/UI.
6. Pensar siempre en la experiencia del usuario final.
