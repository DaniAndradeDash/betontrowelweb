# DESIGN_SYSTEM.md

# Objetivo

Este documento define la identidad visual del proyecto y las reglas que deberán seguir todos los agentes para mantener una experiencia consistente, profesional y escalable.

El Design System es la única fuente de verdad para cualquier decisión relacionada con diseño, interfaz o experiencia de usuario.

---

# Filosofía de diseño

El sitio debe transmitir:

- Profesionalismo.
- Ingeniería.
- Innovación.
- Calidad.
- Precisión.
- Confianza.
- Tecnología.
- Solidez.

El diseño debe sentirse moderno sin depender de animaciones excesivas.

La interfaz debe destacar por su claridad, organización y excelente jerarquía visual.

---

# Principios de diseño

Todo el sitio debe seguir estos principios:

- Menos elementos, mayor impacto.
- Excelente uso del espacio en blanco.
- Contenido fácil de escanear.
- Jerarquía visual clara.
- Consistencia entre páginas.
- Diseño limpio.
- Navegación intuitiva.
- Enfoque Mobile First.
- Accesibilidad desde el diseño.

---

# Identidad visual

La identidad del sitio representa dos elementos:

## Beton Trowel

Representa:

- La marca del fabricante.
- Innovación.
- Calidad.
- Tecnología.
- Maquinaria profesional.

Debe percibirse como la marca protagonista.

---

## Equipos y Superficies de México

Representa:

- Distribuidor oficial.
- Experiencia.
- Respaldo.
- Confianza.
- Atención al cliente.

Debe reforzar credibilidad sin competir visualmente con Beton Trowel.

---

# Paleta de colores

La paleta existente del proyecto deberá mantenerse.

No modificar colores principales sin aprobación.

Todo nuevo componente deberá utilizar únicamente los colores definidos por el proyecto.

Evitar:

- Colores aleatorios.
- Gradientes innecesarios.
- Saturación excesiva.
- Exceso de colores de acento.

La prioridad es mantener consistencia.

---

# Tipografía

La tipografía deberá comunicar profesionalismo.

Debe cumplir:

- Excelente legibilidad.
- Alto contraste.
- Jerarquía clara.
- Espaciado uniforme.

Se recomienda utilizar únicamente una familia tipográfica principal y, como máximo, una secundaria.

Evitar mezclar múltiples fuentes.

---

# Jerarquía tipográfica

Cada página deberá mantener una estructura clara.

Orden recomendado:

- H1
- H2
- H3
- H4
- Texto principal
- Texto secundario
- Etiquetas
- Captions

Nunca utilizar tamaños arbitrarios.

La jerarquía debe ser consistente en todo el sitio.

---

# Espaciado

Todo el proyecto deberá utilizar una escala consistente.

Priorizar:

- Separaciones amplias.
- Aire visual.
- Lectura cómoda.
- Ritmo uniforme.

Evitar:

- Espaciados improvisados.
- Márgenes inconsistentes.
- Componentes demasiado juntos.

---

# Grid

Utilizar un grid consistente.

Todo el contenido deberá alinearse correctamente.

Mantener:

- Márgenes uniformes.
- Columnas equilibradas.
- Buen uso del espacio negativo.

---

# Layout

Las páginas deberán seguir una estructura uniforme.

Generalmente:

- Header
- Hero
- Secciones de contenido
- Productos
- Información técnica
- Llamados a la acción
- Formulario
- Footer

Evitar estructuras diferentes sin necesidad.

---

# Componentes

Todo componente debe mantener:

- Bordes consistentes.
- Sombras discretas.
- Espaciado uniforme.
- Estados visuales claros.
- Excelente legibilidad.

Los componentes deben sentirse parte del mismo sistema.

---

# Botones

Los botones deberán transmitir confianza.

Todos deben tener:

- Estado normal.
- Hover.
- Focus.
- Disabled.
- Active.

Evitar estilos diferentes para acciones similares.

Las acciones principales deben destacarse claramente.

---

# Cards

Las tarjetas deberán ser limpias.

Características:

- Información organizada.
- Buena separación interna.
- Iconografía consistente.
- Imágenes de calidad.
- Jerarquía clara.

No sobrecargar las tarjetas.

---

# Formularios

Los formularios deben ser simples.

Deben incluir:

- Etiquetas claras.
- Validación inmediata.
- Mensajes comprensibles.
- Buen espaciado.
- Estados de éxito y error.

El usuario nunca debe sentirse confundido.

---

# Iconografía

Todos los iconos deberán pertenecer a la misma familia.

No mezclar múltiples estilos.

Los iconos complementan la información, nunca la sustituyen.

---

# Imágenes

Las imágenes deberán ser:

- Profesionales.
- Nítidas.
- Optimizadas.
- Relevantes.

Evitar imágenes genéricas cuando existan fotografías reales del producto.

---

# Responsive Design

Todo el diseño deberá funcionar correctamente en:

- Mobile
- Tablet
- Laptop
- Desktop

No deberán existir elementos que rompan el layout.

---

# Animaciones

Las animaciones no son protagonistas.

Únicamente podrán utilizarse cuando mejoren la experiencia del usuario.

Preferir:

- Transiciones suaves.
- Cambios de estado.
- Microinteracciones.

Evitar:

- Animaciones largas.
- Elementos distractores.
- Movimiento excesivo.

---

# Consistencia

Todo nuevo componente deberá parecer parte del proyecto desde el primer momento.

Si un usuario observa dos páginas distintas, debe percibir que pertenecen al mismo sistema de diseño.

---

# Experiencia de usuario

Toda decisión de diseño deberá responder una pregunta:

> ¿Hace que el usuario encuentre la información más rápido y con mayor confianza?

Si la respuesta es no, el diseño deberá replantearse.

---

# Regla principal

La belleza nunca debe comprometer la claridad.

La modernidad nunca debe comprometer la usabilidad.

La identidad visual siempre tendrá prioridad sobre las tendencias temporales de diseño.
